# SysMon UI/UX 设计

围绕 Windows 系统监控需求，统一资源信息层级、操作方式与宿主主题，兼顾窄栏使用和长列表性能。

## 页面结构

- PageHeader：20px / 28px / 500 标题、作用域 Badge、主机信息、实时状态、刷新控件。
- Resources：四个紧凑卡片，数字优先、趋势次之、设备/核心信息再次。
- Process Explorer：搜索与计数、可排序 DataRow、独立 Inspector。
- Inspector：空态 / 预览 / 固定三种状态，固定后才提供危险操作。

## 样式约定

`lib/client.js` 中 CSS 集中维护 `--sys-canvas/card/subtle/text/secondary/muted/line/brand`
局部 Token，优先映射 DSH `--dsw-alias-*`。浅深色由宿主变量提供，不单独维护主题开关。
页面内边距采用上下 20px、左右 24px，资源网格间隔 12px，卡片内边距 10px 12px。
宿主右栏打开时沿用 12px 紧凑页边距。

浅色采用 `body:not([data-ds-dark-theme])` 标记、`neutral-bluish-75` 画布、
0.5px l3/l4 边框、12px 卡片圆角、lv1/lv1-blur 阴影；深色使用宿主基底、
1px 边框、10px 卡片圆角，不叠加浅色阴影。宿主切换主题后 CSS 即时生效。

CPU / 内存 / 网络 / 磁盘分别映射 color-blue / purple / green / teal-500；
颜色用于资源标题标记、趋势与统计值，警告红黄依然覆盖异常阈值。
交互色继续使用宿主 brand/business Token，避免把类别色误当成状态。

排序采用 control-track + 1px 内边距 + 2px 间隔的 SegmentedControl，
选中项使用 button-primary-fill / label-primary-foreground。
SearchBox 使用 layer-2 背景、6px 圆角、12px 字号和 business-primary 聚焦边框；
计数采用 11px 字号和圆角胶囊；Inspector 统计块使用 8px 圆角、8px 内边距、
20px 数字，浅色背景与阴影与资源卡片保持统一。
动画使用宿主 transition duration / easing，并保留 reduce-motion。

## 联动与选择

- CPU / 内存卡片的文字按钮把列表切换到对应指标的降序排序。
- 排序分段按钮、资源卡片、表头共享同一份 sort 状态，选中状态同步更新。
- Hover / 键盘焦点：临时预览；离开后恢复空态。预览不提供结束按钮。
- Click / Enter：固定当前进程；其余 Hover 不覆盖已固定详情。
- 固定只保存 PID 和创建时间身份，详情值从每份新快照读取，避免显示旧数值。
- 进程消失或 PID 创建时间变化后，清除固定选择和确认状态。
- Esc / 取消固定：恢复到对应 PID 控件；该行不在 DOM 中时不强行移动焦点。
- 搜索清除后将焦点交还输入框；空结果给出恢复提示。
- 结束操作仍需三秒内再次点击，并沿用后端创建时间校验。

## 响应式与稳定性

`.sys-root` 使用命名 `sysmon` container；`.sys-list` 使用 `syslist` container。
在宽浏览器中的窄 DSH pane 也会正确折叠，不依赖 viewport media query。

- 内容宽 ≤ 1100px：Inspector 折到列表下，提供「查看详情」入口。
- 内容宽 ≤ 900px：资源卡片从四列变为两列。
- 内容宽 ≤ 480px：资源卡片一列，控件换行。
- 列表自身宽 ≤ 700px：隐藏工作集和线程列，详情中仍可查看。
- 表格保留自己的横向滚动，避免把整页撑宽。
- 每页渲染至多 100 行，全部结果可翻页访问；固定图表/列表空间、reduce-motion 和可见焦点环。

## 验证边界

Edge 无头浏览器中使用 React 18.3.1 和测试快照验证，不把截图当作真实监控数据。
测试覆盖排序联动、预览不暴露结束操作、固定不被 Hover 覆盖、键盘固定与 Esc、
搜索恢复、断线恢复，以及 1440px viewport 内 760px 插件容器和 390px 手机宽度。
浏览器测试覆盖交互和布局；DSH 桌面应用中的视觉效果由手动验收确认。


## 列表性能与验证

列表每页 100 条，配合固定行高窗口、滚动帧合并和尺寸观察器减少 DOM；筛选和排序始终作用于全量快照。固定选择通过胶囊保留和清除，图表历史保持 90 点。当前页面仅四张资源卡片，无需额外延迟挂载。

新增浏览器验证使用 1200 条测试进程：窗口模式 DOM 少于 40 条，滚动到底可访问页尾；第二页从第 101 条开始，
搜索可找到第 1200 条；筛选不匹配时固定选择胶囊仍在，可取消固定和结束操作入口。
这验证了访问完整性与 DOM 行数上限，不等于已经测得 CPU 或帧率提升。


### 已执行：页内窗口化

- 页内条数超过 80 时启用；小列表保持普通 DOM，避免额外窗口逻辑影响交互。
- 行高和表头均为 32px；顶部与底部占位保持总滚动高度，表头继续 sticky。
- 上下各 8 行 overscan；一次动画帧内合并多次滚动和尺寸变化。
- 窗口范围不变时复用原状态对象，不触发多余更新。
- 行 key 使用 PID + 创建时间，避免排序/翻页后把 DOM 身份分配给别的进程。
- 表格提供全量 aria-rowcount 和全局 aria-rowindex，占位不暴露给辅助技术。
- 焦点进入表格时挂载当前页全部行（最多 100），保留完整 Tab 顺序和焦点；
  焦点离开后恢复窗口模式。筛选/排序重置滚动位置，翻页保留固定选择。
- 浏览器已验证：1200 条数据、页尾可达、窗口 DOM 上限、键盘固定页尾进程、
  跨页搜索与选择胶囊清除，以及原有主题、窄栏和离线恢复。

Windows 宿主已经预留标题栏高度，监控页不再叠加标题栏 clearance，避免顶部双重留白。侧栏中文名称为「系统监控」，英文名称为「System Monitor」。

宽屏使用一致的四列网格与 12px 列间距：资源卡片各占一列，进程列表占前三列，进程详情占第四列，因此磁盘卡片与详情左右边界、宽度完全一致。内容宽度不超过 1100px 时详情折叠到下方，列表恢复整行。

## 资源区分组布局

宽容器使用左右两个等宽分组，每组两列。左组首行固定为内存与 GPU；第二行起每块物理磁盘占一格，磁盘数量增加时向下扩展。右组固定为 CPU 与网络两张卡，保持顶部对齐，不随磁盘数量复制。CPU 展示完整型号、物理核心、逻辑处理器、插槽及平均频率，并提供带编号和占用百分比的逻辑处理器小格。网络接口列表与逻辑处理器列表具有内部滚动上限，避免把所有资源卡撑到异常高度。

容器宽度为 581–1000px 时资源重排为两列，优先展示 CPU/网络，其次内存/GPU，磁盘置后；不超过 580px 时改为单列。颜色由资源类型确定，不再依赖卡片排列序号。无磁盘计数器时保留一张不可用卡；无 GPU 时显示明确提示。GPU 展示真实利用率、历史曲线、设备名称及显存容量，计数器不可用时明确提示。

### 网络卡片高度与接口分组

CPU 与网络保持右侧两列定位，但网络卡片按自身内容收缩，不跟随 CPU 卡片拉伸。上下行图表后紧接有流量的接口，按当前上下行总速率排序；暂无流量的接口放入原生 details/summary 折叠区，可鼠标或键盘展开查看。所有接口仍保留，聚合速率口径不变。

当快照根本不含 GPU 字段时，表示宿主接口尚未提供该信息，显示完全退出并重启 DSH 的提示；显式返回空设备列表或不可用状态时才显示设备不可用。页面刷新不能替代 Host 模块重启。

### CPU 与网络历史图

CPU 使用固定 0–100% 纵轴及 25% 网格；上下行网络分别使用带单位的自动纵轴（1/2/5 易读刻度并保留顶部余量）。曲线直接连接真实采样点，不进行平滑插值。横轴按真实时间间隔绘制并标注观察窗口；缺失值、超过 10 秒的间隔均断开。无数据时显示等待采样，不绘制零值曲线。

每张图提供当前值、峰值和均值；峰值/均值只统计窗口内有效样本。悬停或触摸可查看最近采样点的时间及数值，缺失采样明确标注。图表可以 Tab 聚焦，通过左右键逐点查看，Home/End 跳转首尾；最近有效点以标记显示。内存也使用相同的详细历史图：固定 0–100% 量程，支持采样查看及峰值/均值。

### 图表横向空间

CPU、内存、上下行网络图取消左侧固定宽度的纵轴栏。绘图区横向占满卡片内容宽度，纵轴刻度置于绘图区右侧内部、网格线附近，并提供局部底色保持可读性；刻度层不拦截鼠标或触摸。时间轴与绘图区左右边缘对齐。绘图、十字线和采样选择共用同一坐标区域，保持查看数值与实际曲线位置一致。

### 逻辑处理器块状柱体

逐逻辑处理器展示改为紧凑块状柱体网格，每块上方为 CPU 编号，下方为实时占用百分比，半透明色块按 0–100% 自底部向上填充。色块位于文字后方，保持编号与数值可读；无数据以破折号显示，不绘制填充。固定每行四个柱体，大量处理器时保留内部滚动。悬停提示及无障碍名称明确指出这是逻辑处理器，避免与上方物理核心数混淆。

逻辑处理器柱体置于与网络“其他接口”一致的原生折叠区，默认收起。摘要显示“逻辑处理器 · 数量”，鼠标点击或键盘 Enter/Space 展开和收起；展开后固定每行四个，数据刷新保持用户的展开状态。

### 默认四列高度对齐

CPU 逻辑处理器和网络其他接口均收起时，资源区两组等高：内存/GPU 与下方磁盘组成的左侧列，和右侧 CPU、网络卡片统一顶部、底部边缘。左组额外高度由首行内存/GPU 吸收，磁盘行保持内容高度。任一折叠区展开时，仅对应卡片超出收起基准按内容增高，左侧两列及其他卡片保持基准高度；重新收起后自动恢复对齐。单列移动布局保持内容高度，避免为对齐产生额外拉伸。网络接口仍紧接图表，不重新引入接口前的自动留白。

基准高度通过不可交互、不可见的收起布局副本测量，避免展开内容参与计算。数据刷新及宽度变化时重新测量收起布局；不缓存展开后的高度，也不通过切换整个资源区的对齐方式实现展开。测量副本同步移除，ResizeObserver 随组件卸载释放。

### GPU 实时监控

单 GPU 直接展示，多 GPU 通过顶部编号按钮切换。上方是当前利用率及“最繁忙引擎”口径，下方使用与 CPU/内存一致的全宽百分比曲线，提供时间轴、峰值、均值与采样查看。设备型号和显存容量置于曲线后，底部展示最活跃的三个引擎及其占用条。采集预热、计数器不可用或旧宿主不提供利用率时显示明确状态与破折号；不会用 0% 表示无数据。选中设备按身份匹配，设备消失后回退首个可用设备。

## 非全屏窗口与窄插件面板

资源布局按插件容器宽度切换：超过 1000px 保留四列及收起高度基准；581–1000px 改为两列，首行 CPU/网络、第二行内存/GPU，磁盘排在后面；不超过 580px 改为同顺序的单列。中窄布局不强制四列等高，也不执行四列的基准高度测量，展开内容不会改变其他资源组的高度。

中窄布局提供固定在滚动区域顶部的工具栏和“资源/进程”跳转按钮，跳转同时转移焦点，给工具栏预留滚动偏移以免遮挡标题。元信息单独一行，控件允许换行。列表高度根据窗口高度在 240–440px 之间调整。进程列表宽度不超过 520px 时保留 PID、CPU、内存、名称四列，隐藏的工作集、线程数及 CPU 时间仍在进程详情中查看。CPU 柱体始终保持每行四个。窗口缩放不会重置暂停、搜索或固定进程。

回归覆盖 1024×720、900×640、620×640、宽窗口内 760px 面板和 390px 移动布局，检查资源顺序、工具栏遮挡、表格横向溢出、图表刻度重叠和章节导航焦点。

GPU 引擎占用条使用与 CPU、网络一致的原生折叠区，默认收起。摘要显示“引擎占用 · 数量”，点击或键盘 Enter/Space 展开后查看当前占用最高的至多三个引擎。采样刷新保留展开状态，无引擎数据时不显示空折叠入口。

波形首次加载：CPU、内存、GPU 和网络在预热时显示原位扫描光带与采样状态；单点数据提示“正在形成趋势”，真实曲线就绪后淡入。暂停、离线和指标不可用时不持续播放加载动效，遵循系统减少动态效果设置。加载层不占额外高度，也不生成模拟曲线。
