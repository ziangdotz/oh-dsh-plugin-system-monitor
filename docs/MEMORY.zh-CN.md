# 内存优化记录

目标是减少插件新增的内存，保留系统资源、磁盘、进程浏览与结束操作。版本保持 `0.1.0`。
DSH 已有的 Node、Electron、React 基线不属于插件独占内存，但新增的原生进程、Host 分配、页面堆、DOM 和绘制分配均需要评估。

## 已完成的实现

- C 原生采集器替换脚本运行时；只链接 Windows 自带 DLL，不使用托管运行时。
- 进程使用 Toolhelp 快照、有限查询权限、进程时间与工作集接口；无法读取的字段为 null。
- 网卡使用 `GetIfTable2`，及时释放接口表。
- 物理磁盘使用 `QueryDosDeviceW` 枚举和 `IOCTL_DISK_PERFORMANCE` 累计字节数，在 Host 计算差值速率。
- 设备枚举缓冲区按需增长并复用，不重复加载性能计数器提供程序。设备计数器不可读时报告警告。
- 进程、设备和父进程句柄均有关闭路径。父 Host 退出、标准输出断开、插件卸载或无快照请求时，采集器退出。
- 结束进程使用同一原生程序的短命令模式，检查关键进程标志和创建时间，再通过同一个内核句柄结束进程。
- Host 直接补充采集对象中的计算字段，减少对象及数组复制；硬件描述复用采样数据，不在每次快照请求时重复枚举 CPU。卸载时主动清空进程、网卡、磁盘和历史缓存。
- 进程列表保留分页和窗口化；搜索仍覆盖所有进程，不丢弃数据来降低数字。页面字体复用宿主的 `--dsw-font-family`。

## 测量方法

`node scripts/memory-smoke.mjs` 默认持续 60 秒，通过两个常驻原生计量进程每约 2 秒记录采集器工作集、私有内存、句柄数，以及隔离 Host 的私有内存、RSS 和堆变化。计量进程本身不计入插件结果，生产插件不会启动计量进程。
不会强制 GC，也不会调用 EmptyWorkingSet 或调整工作集上限。

```powershell
$env:SYSMON_MEMORY_SECONDS = '1800'
$env:SYSMON_MEMORY_REPORT = 'artifacts/memory-native-30min.json'
node scripts/memory-smoke.mjs
```

工作集包含驻留的共享和私有页；Private Bytes 是私有提交量；JS 堆只是进程分配的一部分。它们不能相加作为总内存。
隔离 Node 的 RSS 差值包含其 JIT、堆容量和测量脚本开销，不能直接当成真实 DSH 中插件的精确增量。

## 初步结果与边界

同机旧采集链路 60 秒测量的平均工作集为 116.28 MiB、私有内存 93.99 MiB。
原生方案已通过真实 CPU、网卡、磁盘、进程身份和结束操作检查；移除性能计数器提供程序链路后，采集器工作集约 4–5 MiB，私有内存约 1 MiB。
最终长期结果以 `artifacts/memory-native-30min.json` 为准。

页面另外使用两种隔离基线测量：开发版 React 页面，以及从本机 DSH 0.2.2-rc.1 发行文件加载的真实前端内核。页面数据为 360 条测试进程，结果不能冒充真实 DSH 会话的整机总占用。
浏览器进程中的字体、布局、JIT、DOM 和绘制缓存也会增长，因此仅证明“JS 堆小于 10 MiB”不等于证明“插件全部内存小于 10 MiB”。

当前尚未完成整个插件全部新增内存 ≤10 MiB 的验收，不能将采集器结果当成整体达标结果。

## 持续观察

采集路径已完成 30 分钟观察：860 次约两秒间隔采样，平均工作集 4.526 MiB、峰值 5.281 MiB，平均私有内存 0.996 MiB、峰值 1.801 MiB；首尾句柄数均为 74，无请求后采集器退出。采样期间系统有 344–384 个进程，没有采集警告。

该轮查询每次启动一个内存读取命令，Host 增量混入了反复创建测量子进程的分配开销。因此该轮 Host RSS/堆差值不作为生产插件的独占内存结论；之后加入常驻原生计量选项并单独复测。

页面使用发行内核持续刷新 10 分钟，360 条测试进程下保持 22 条可见进程行；观察点 DOM 为 665、监听器为 227，JS 堆在 9.689–15.713 MiB 间自然循环回落。该堆包含共享测试内核，不能用单次基线差值推断精确保留内存。浏览器进程另有字体、布局和绘制分配，目前没有整体 ≤10 MiB 的达标证据。

## 常驻计量器对照结果

最终二进制增加常驻内存计量选项后完成 5 分钟、150 次采样复测。默认采集路径没有改动。计量器始终是测试进程，不在生产插件中启动。

| 项目 | 平均 | 峰值 |
| --- | --- | --- |
| 采集器工作集 | 4.366 MiB | 4.531 MiB |
| 采集器私有内存 | 0.926 MiB | 1.156 MiB |
| 隔离 Host 新增私有提交 | 1.640 MiB | 3.301 MiB |
| 隔离 Host RSS 增量 | 6.259 MiB | 7.895 MiB |
| 隔离 Host JS 堆增量 | 0.856 MiB | 1.372 MiB |

按每个采样点相加采集器私有内存与隔离 Host 私有提交增量，后台平均新增私有提交约 2.566 MiB、峰值约 4.215 MiB。工作集和 RSS 另列，不与私有提交混加。首尾句柄数仍为 74，空闲退出通过。

页面 10 分钟对照中，全部 renderer 进程的私有提交净增加约 12.469 MiB，且包含共享内核与浏览器分配行为；这不等于真实 DSH 会话中插件的精确独占增量，但说明仅依据很小的 JS 堆差值宣称整体达标是不可靠的。

当前结论：原生采集器和后台私有提交已显著下降，完整插件 ≤10 MiB 的目标仍未通过验收。真实 DSH 的页面渲染增量仍需进一步定位。原始结果在项目 artifacts/ 目录，发行包不携带测试运行数据。

## GPU 利用率版本的内存变化

以上 4–5 MiB 工作集、约 1 MiB 私有内存结果均属于未启用 GPU Engine 计数器的历史版本，不能代表当前版本。GPU 利用率版本增加一个共享 PDH 查询及复用的计数器数组缓冲区；原始进程级计数器只用于 Host 聚合，不随快照下发到浏览器。查询和缓冲区随采集器生命周期释放。

2026-11-07 对当前版本进行 30 秒短测（15 个观察点）：采集器平均工作集 13.559 MiB、峰值 13.695 MiB；平均私有内存 6.323 MiB、峰值 6.457 MiB；首尾句柄数均为 147，空闲退出通过。隔离 Host 平均新增私有提交 1.055 MiB、峰值 1.809 MiB。原始结果为 `artifacts/memory-gpu-30s.json`。本轮没有强制 GC 或清空工作集；短测不代替长时间稳定性验证，也不代表完整插件的精确独占内存。当前原生工作集已超过 10 MiB，不能宣称完整插件新增内存 ≤10 MiB。

## 2026-11-08 热更新版本短测

60 秒、30 个观察点、8 个逻辑处理器，系统进程数量以 `artifacts/runtime-hotplug-60s.json` 为准。采集器平均整机 CPU 为 0.1273%，两秒观察区间峰值 1.3645%；隔离 Host 平均 0.0234%，区间峰值 0.2929%。采集器平均工作集 13.496 MiB，峰值 13.633 MiB；平均私有提交 6.238 MiB，峰值 6.602 MiB。隔离 Host 平均私有提交增量 1.519 MiB，峰值 2.348 MiB。首尾句柄数 150 / 149，无请求后采集器退出。

CPU 按进程 CPU 时间差除以时间间隔与逻辑处理器数计算；Host 数据包含测试驱动开销，未包含真实 DSH 页面渲染。没有强制 GC 或清空工作集。这是短时间后台测量，不能代表完整插件的精确独占资源，也不代表实际物理插拔时的峰值。
